# Portfolio Secrétariat — One-page (HTML)

Version « assistante administrative / secrétaire » du portfolio QA (https://laetitia3529.github.io/portfolio/), même design.

## Fichiers
- `index.html` : page principale (HTML + CSS + JS)
- `Orange.png`, `groupement-achat.png` : visuels des cartes
- `404.html`, `robots.txt`

## Ouvrir sur ton PC
Double-clique sur `index.html` : la page s’ouvre dans ton navigateur. Garde les images dans le même dossier.

## Publication (GitHub Pages)
Nouveau dépôt (ex. `portfolio-secretariat`) → Settings → Pages → branche `main`, dossier `/root`.
